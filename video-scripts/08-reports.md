# Clip 08 — Reports (closing clip)

**Screen:** `/admin/reports` — KPI row (users, doctors, appointments, conversations), appointment status breakdown (with cancellation % / completion %), user breakdown, doctor load chart
**Motion:** Frozen — same treatment as clips 01, 02, and 04: paused screenshot with a slow Ken Burns zoom (~102% → ~110%). This is the last clip in the video, so it doubles as the outro — it bookends clip 01's intro rather than just being "one more page."

## Script

1. وكل الأرقام والحجوزات والدكاترة اللي شفناها... بتتلخص كلها هنا، في صفحة التقارير.
2. عدد المرضى، الأطباء، المواعيد، المحادثات... كل الأرقام قدامك.
3. نسبة الإلغاء، نسبة الإكمال، وحمل شغل كل دكتور.
4. كل ده... من غير ما تجمع بيانات من عشر أماكن.
5. ده كلينيكا إيه آي...
6. جرّبها دلوقتي.

Line 1 now doubles as the bridge from Clip 07 (appointments/queue) — it references "الحجوزات والدكاترة اللي شفناها" directly, so the cut into this frozen closing screen doesn't feel like a hard topic change.
